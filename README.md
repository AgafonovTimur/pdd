# Тренажёр дорожных знаков

Одностраничное HTML-приложение для тренировки распознавания дорожных знаков. Показывает знак и 4 варианта названия, нужно выбрать правильный.

---

## 1. Функции приложения

- **Викторина с 4 вариантами ответа**: на экране показывается изображение знака и 4 кнопки с названиями (1 верное + 3 случайных неверных из выбранных категорий).
- **Проверка ответа**:
  - При верном ответе кнопка подсвечивается зелёным (`flash-correct`), и приложение автоматически переходит к следующему вопросу через 500 мс.
  - При неверном ответе выбранная кнопка подсвечивается красным (`flash-wrong`), правильная — зелёным, а также появляется блок с названием и описанием правильного знака и кнопка «Далее».
- **Панель настроек с категориями**: список категорий знаков в виде плиток-переключателей (`cat-tile`). Активные категории выделены, повторный клик отключает категорию. Вопросы формируются только из знаков включённых категорий.
- **Автоматическая генерация вопросов**: при каждом переходе к следующему вопросу случайно выбирается знак и случайные неверные варианты из текущего пула (перемешивание через `shuffle`).
- **Скроллинг вместо кликов** для управления окном настроек и перехода к следующему вопросу (см. раздел «Горячие клавиши»).

---

## 2. Горячие клавиши / жесты

Обычных клавиатурных горячих клавиш в приложении нет. Управление реализовано через **колесо мыши / скролл**:

| Действие | Жест |
|---|---|
| Открыть панель настроек (категории) | Прокрутка колесом **вверх** (`deltaY < 0`) |
| Закрыть панель настроек | Прокрутка колесом **вниз** (`deltaY > 0`), если панель открыта |
| Перейти к следующему вопросу (после показа ответа) | Прокрутка колесом **вниз** (`deltaY > 0`), если кнопка «Далее» видна |
| Сделать знак темнее/светлее | кнопки + / - |
| Отвечать можно на кнопки клавиатуры | 1 2 3 4, ф ы в а(a s d f) |

Также доступны обычные клики:
- Клик по плитке категории — включает/выключает категорию;
- Клик по варианту ответа — выбирает ответ;
- Клик по кнопке «Далее» — переход к следующему вопросу;
- Клик вне панели настроек (по затемнённой области) — закрывает панель.

---

## 3. Что можно поменять через меню (настройки внутри приложения)

Меню настроек открывается скроллом вверх и содержит:

- **Плитки категорий знаков** — можно включать/выключать любые категории. Выключенные категории исключаются из пула вопросов (кнопка теряет класс `active`).
- Больше пользовательских настроек в текущем меню нет — оно ограничено выбором категорий.

---

## 4. Что можно поменять через настройки внутри файла (CSS-переменные в `:root`)

Все визуальные параметры вынесены в CSS-переменные в начале файла (`<style>` → `:root`). Основные группы:

### Общие цвета
- `--bg` — цвет фона
- `--tile` — цвет плиток (варианты ответов, категории)
- `--tile-text` — цвет текста на плитках
- `--shadow-color` — цвет тени под плитками
- `--flash-correct-color`, `--flash-correct-opacity` — цвет и прозрачность подсветки верного ответа
- `--flash-wrong-color`, `--flash-wrong-opacity` — цвет и прозрачность подсветки неверного ответа

### Блок с названием и описанием знака при неверном ответе (`#answerInfo`)
- `--answer-info-top`, `--answer-info-left` — позиция блока (px от левого верхнего угла экрана)
- `--answer-info-width` — ширина блока
- `--answer-info-max-height` — максимальная высота (дальше появляется вертикальный скролл)
- `--answer-info-gap` — расстояние между названием и описанием
- `--answer-info-padding` — внутренние отступы
- `--answer-name-font-size`, `--answer-name-text-color` — размер и цвет шрифта названия
- `--answer-desc-font-size`, `--answer-desc-text-color` — размер и цвет шрифта описания

### Кнопка «Далее» (`#nextBtn`)
- `--next-btn-top`, `--next-btn-left` — позиция кнопки (px)
- `--next-btn-width`, `--next-btn-height` — размеры кнопки
- `--next-btn-font-size` — размер шрифта
- `--next-btn-text-color` — цвет текста
- `--next-btn-bg-color` — цвет фона кнопки
- `--next-btn-text-align` — выравнивание текста
- `--next-btn-padding` — внутренние отступы

### Окно настроек (`#settingsPanel`)
- `--settings-panel-width`, `--settings-panel-height` — размеры окна
- `--settings-panel-padding` — внутренние отступы
- `--settings-panel-top`, `--settings-panel-left` — смещение окна от центра экрана
- `--cat-tile-height`, `--cat-tile-min-width`, `--cat-tile-font-size` — размеры и шрифт плиток категорий

### Главный экран викторины (`#quizScreen`)
- `--sign-box-width`, `--sign-box-height` — размеры блока с изображением знака
- `--sign-box-top`, `--sign-box-left` — смещение блока знака от центра экрана
- `--quiz-gap` — расстояние между знаком и сеткой вариантов ответа
- `--options-grid-width` — ширина сетки вариантов ответа
- `--opt-tile-height`, `--opt-tile-font-size` — высота и размер шрифта плиток вариантов ответа

## Структура данных (EMBEDDED_DATA)

Приложение ожидает переменную `EMBEDDED_DATA` с объектом вида:

```json
{
  "categories": [
    { "id": "warning", "label": "Предупреждающие" }
  ],
  "signs": [
    {
      "id": "sign1",
      "category": "warning",
      "name": "Название знака",
      "description": "Описание знака",
      "image": "путь_или_data_url_картинки"
    }
  ]
}
```
